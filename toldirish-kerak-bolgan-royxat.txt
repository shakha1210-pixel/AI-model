KOD YOZISH AGENTI — TO'LDIRILISHI KERAK BO'LGAN NARSALAR RO'YXATI
===================================================================
Ushbu fayl loyihada SIZ shaxsan to'ldirishingiz yoki hal qilishingiz kerak
bo'lgan barcha joylarni bir joyga jamlaydi.


1) DARHOL KERAK — DASTURNI ISHGA TUSHIRISH UCHUN
-------------------------------------------------
[ ] agent-project/.env.example faylidan nusxa olib, xuddi shu papkada
    ".env" nomli yangi fayl yarating (xavfsizlik uchun bu fayl avtomatik
    yaratilmaydi — o'zingiz nusxalashingiz kerak):
      cp .env.example .env
    So'ng .env faylini ochib quyidagilarni kiriting:
    - ANTHROPIC_API_KEY   (https://console.anthropic.com/settings/keys dan oling)
    - GEMINI_API_KEY      (https://aistudio.google.com/app/apikey dan oling)
    - LEONARDO_API_KEY    (https://app.leonardo.ai/api-access dan oling —
      "Rasm chizish" domeni uchun kerak; qo'shilmaguncha faqat shu domen
      ishlamaydi, qolgan domenlar (kod/g'oya/qidiruv) ta'sirlanmaydi)
    Ikkalasi ham odatda bepul sinov limiti bilan boshlanadi, lekin
    Anthropic uchun ro'yxatdan o'tish va to'lov kartasi kerak bo'lishi mumkin.
    "Qidiruv/hujjat tahlili" domeni uchun ALOHIDA kalit kerak EMAS — xuddi
    shu GEMINI_API_KEY bilan kuchliroq model (GEMINI_RESEARCH_MODEL,
    standart: gemini-3.5-flash) ishlatiladi.

[ ] Python 3.10+ o'rnatilganini tekshiring, so'ng terminalda:
      pip install -r requirements.txt
      uvicorn main:app --reload
    va brauzerda http://localhost:8000 oching.

3) KEYINGI BOSQICHLARDA KERAK — main.py DAGI BAYROQLAR
--------------------------------------------------------
Quyidagi funksiyalar allaqachon YOZILGAN va ISHLAYDI, lekin standart
holatda O'CHIRILGAN (.env faylida "false" qilib qo'yilgan). Har birini
qachon yoqishni o'zingiz hal qilasiz:

[ ] ENABLE_DATABASE=true — suhbatlarni doimiy saqlash (database.py).
    Standart: DATABASE_URL=sqlite:///./app.db (hech narsa o'rnatish shart
    emas). Productionga chiqqanda PostgreSQL'ga o'tkazishni tavsiya
    qilamiz — DATABASE_URL'ni shunga mos yozing.

[ ] ENABLE_AUTH=true — ro'yxatdan o'tish/kirish tizimi (auth.py,
    login.html, register.html). ENABLE_DATABASE ham true bo'lishi shart.
    JWT_SECRET qiymatini albatta o'zgartiring (tasodifiy uzun matn,
    masalan terminalda: openssl rand -hex 32).

[ ] ENABLE_RATE_LIMIT=true — bir foydalanuvchidan daqiqasiga nechta
    so'rov qabul qilinishini cheklaydi (rate_limiter.py). Standart: 60
    soniyada 20 ta so'rov — RATE_LIMIT_MAX_REQUESTS va
    RATE_LIMIT_WINDOW_SECONDS orqali o'zgartirishingiz mumkin.

[ ] ENABLE_TOOLS=true — Claude'ga kod yozish VA uni ijro etish
    imkoniyatini beradi (tools.py).
    !!! MUHIM XAVFSIZLIK QARORI !!!
    tools.py dagi run_python_code() hozircha kodni to'g'ridan-to'g'ri
    shu serverning o'zida ishga tushiradi — bu FAQAT DEMO uchun xavfsiz.
    Haqiqiy foydalanuvchilarga ochishdan oldin quyidagilardan birini
    TANLASHINGIZ VA ULASHINGIZ kerak:
      - Docker konteynerida tarmoqsiz ishga tushirish, YOKI
      - Hostlangan sandbox xizmati (masalan E2B.dev, Modal, Piston), YOKI
      - gVisor / Firecracker kabi izolyatsiya texnologiyasi.
    Tanlovingizni tools.py fayliga izoh sifatida yozib qo'ying.

[ ] ENABLE_GITHUB_TOOL=true — Claude'ga GitHub repositoriy bilan ishlash
    imkoniyatini beradi (github_tool.py): fayl o'qish/yozish, papka
    ro'yxati, Pull Request ochish. run_python_code'dan farqli — bu
    serverda kod ijro etmaydi, shuning uchun sandbox tasdiqlash SHART
    emas. GITHUB_TOKEN kerak (https://github.com/settings/personal-
    access-tokens — "fine-grained" token, FAQAT kerakli repo(lar)ga va
    Contents+Pull requests (Read&Write) huquqiga cheklab yarating).
    !!! DIQQAT: prompt injection xavfi — agent foydalanuvchi xabari yoki
    biriktirilgan fayl matnidagi yashirin ko'rsatmalarga ergashib repoga
    kutilmagan o'zgartirish kiritishi mumkin. Tokenni sinov repositoriyga
    yo'naltiring yoki main/master branch'ni himoyalab, agentga faqat
    boshqa branch + Pull Request orqali ishlashga ruxsat bering.

[ ] ENABLE_GOOGLE_DOCS_TOOL=true — Claude'ga Google Docs hujjatlari bilan
    ishlash (o'qish, yaratish) imkonini beradi (google_docs_tool.py).
    auth.py bilan BIR XIL GOOGLE_CLIENT_ID/GOOGLE_CLIENT_SECRET qayta
    ishlatiladi — yangi OAuth client yaratish shart emas, lekin Google
    Cloud Console'dagi o'sha client'ning "Authorized redirect URIs"
    ro'yxatiga GOOGLE_DOCS_REDIRECT_URI qiymatini (standart:
    http://127.0.0.1:8000/google-docs/callback, productionda o'z
    domeningiz bilan) QO'SHISHINGIZ kerak. Cloud Console > Google Auth
    Platform > Audience bo'limida ilova "Testing" holatida qolsa,
    "Test users" ro'yxatiga qaysi Google email'lar Docs'ni ulay olishini
    qo'shishni unutmang (himoya paytida faqat shu email'lar ishlaydi).
    Ulanish sessiya darajasida ishlaydi (foydalanuvchi sozlamalar
    sahifasidan "Google Docs ulash" tugmasini bosadi) — to'liq
    ro'yxatdan o'tish/login talab qilinmaydi.

[x] ENABLE_PROJECTS=true / ENABLE_PROJECT_FILES_TOOL=true — "Loyihalar"
    bo'limi (suhbat va fayllarni guruhlaydigan papkalar) va Claude uchun
    loyiha fayllarini o'qish/yozish tool'i (project_tool.py). Ikkalasi
    ham allaqachon yoqilgan va ishlaydi — qo'shimcha kalit/token kerak
    emas. "Mehmon sifatida davom etish" imkoniyati ATAYLAB olib
    tashlangan: ENABLE_AUTH=true bo'lgani uchun endi /chat, /chat/stream,
    /files/*, /history, /sessions, /projects/* — barchasi token talab
    qiladi (login SHART). Har-user chegaralar (.env orqali
    o'zgartiriladi): MAX_SESSIONS_PER_USER=30, MAX_PROJECTS_PER_USER=5,
    MAX_PROJECT_FILES=10 — chegaraga yetganda foydalanuvchiga aniq xabar
    (va "Pro'ga o'tish" tugmasi — hozircha faqat ko'rinish, haqiqiy
    to'lov/obuna tizimi ULANMAGAN) bilan 403 qaytadi.
